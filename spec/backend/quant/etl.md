# spec/backend/quant/etl — 调度、消费、限速、并发

| 任务 | 时间 | 说明 |
|---|---|---|
| basic | 00:05 | 股票基础信息 |
| daily_update | 16:45 + 18:30 兜底 | 收盘更新（`misfire 1h`，单实例） |

| financials | 周日 02:00 | 财务报表 |

## 2. 消费

- `etl_tasks` 队列表，后台单消费者：`PENDING → RUNNING → COMPLETED/FAILED/SKIPPED`，
  进度 `progress`，错误进 `error`，每次一任务，失败不阻塞后项只记行。
- 定时与手动统一入队（调度器只提交不直跑），全局串行由消费者保证。
- 财报按“季度覆盖率≥95%”判定完成，不再按“有一条记录”或“40 个季度”跳过；
  指定报告期用 `period` 参数，不用公告截止 `end_date`。

## 3. 并发与限速

- 全进程单 `*sql.DB`，`SetMaxOpenConns(1)` + `sync.Mutex` 串行（替代现 RLock）；
  upsert 按批次持锁，批次间释放，读查询可穿插；超 1s 的 DB 操作记慢日志。
- tushare provider：`net/http` 直调，串行限速，不并发打源站。
- 错误分级：分钟限流只退避重试不标记；日限额按上海日期标记、当天跳过、次日自动恢复；
  权限不足返回哨兵错误，任务记 SKIPPED；复权请求失败或因子不完整时拒绝本日写入；历史NULL保留为缺口，不填1。

## 4. 分红采集完整性

- dividend显式请求stock_dividend已有的全部业务字段，包括默认不返回的base_date/base_share。
- 单证券请求失败或写库失败立即返回含证券代码的错误，保留原错误链供队列分类；不得继续后报完成。
- 单次返回达到来源2000行上限即报完整性错误，本批不写入；后续需有可靠分片方案才能接受。
- 已写入的前序证券保留，重试沿用现有主键upsert；任务失败不代表整任务回滚。
- 空响应允许无分红，但不证明历史覆盖完整；任务成功也不等于公司行动可用于回测。
- 字段口径与回测前置条件见[strategy/data.md](../../strategy/data.md#6-公司行动数据入口)。

## 5. 行情与复权写入前校验

- 日线与复权作为同日输入；请求失败、空日线、重复证券、日期不符、缺失或非正有限因子即失败。
- 所有校验在dedupeUpsert前完成；不将失败响应的NULL覆盖已有因子，也不填1或沿用旧因子配新价格。
- 范围同步遇首个失败返回含日期的错误，保留错误链；已成功日期不回滚，不将失败任务标成功。
- 历史NULL需要恢复来源后定向/强制回补，现有按行数跳过机制不证明因子完整。

## 6. 数据源地址与凭据选择

TUSHARE_TOKEN_TYPE只选择SHORT_TUSHARE_TOKEN或LONG_TUSHARE_TOKEN，不代表账户积分或接口授权。
可选TUSHARE_API_URL覆盖历史默认地址；显式地址使用通用逐证券财务流程及至少500ms调用间隔，避免专线批量假设。
空地址保持旧部署兼容：short专线、long既有地址。官方地址按[Tushare HTTP文档](https://tushare.pro/document/1?doc_id=130)核验。
2026-09-10同一新short配置凭据在官方HTTPS日线请求返回code=0，旧专线返回无效token；据此改部署地址。
积分权限必须按具体接口实测，不根据变量名推断；不记录凭据，不将数据源可访问当作全库已补齐。

## 7. 分红来源内容一致性

官方同公告日不同阶段、甚至同阶段都可能返回不同基准股本/现金额的方案，不能用公告日或阶段作唯一键。
0006后按全部16个业务字段精确去重，内容不同追加保留，完全相同幂等保留首次采集时间。
证券、报告期、阶段须存在；公告日可NULL，分红写入使用SQLite IS比较键，不伪造公告日。
验收须逐字段比较官方返回与本地记录，而非仅按任务完成或表行数判断；实施事件选择仍另行校验。

## 8. 卖方路由下最新概念与行业

用户授权使用截图配套凭据及https://tuaremax.top；凭据仅留部署配置，不写文档。
概念任务固定使用ths_index(exchange=A,type=N)及ths_member，不由TOKEN_TYPE/专线路由推断接口权限。
概念目录与成分使用现有staging原子发布；任一来源/入库失败立即停止，空目录或异常空成分拒绝覆盖。
申万index_member_all按2000条分页，检测重复键/页与安全上限，收齐后才替换当前行业关联。
官方概念成分是最新快照，不代表历史时点可知；本轮不新增板块日线/资金流新表。

## 9. 10000积分高权限与主力/历史数据补采

- 针对 10000 积分短凭据有效期（2天）内的定向补采：覆盖资金流向 3 年（含超大单/大单主力买卖及净额）、
  融资融券 3 年（杠杆主力明细）、沪深港通资金（外资北向主力）2021 年至今全量。
- 修复自定义地址下短 token 模式识别：当 TUSHARE_TOKEN_TYPE=short 时保持 isShort=true，
  允许使用财报批量接口（每批 100 只股票），解除逐证券单日 500 条限制；调用仍保持 ≥400ms 间隔防封。
- 补数路由参数支持：moneyflow 与 margin 支持透传 start_date/end_date 与 years，
  保持已存在交易日检查机制，支持断点续传与幂等入库。
