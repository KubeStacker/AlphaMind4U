# continuous_research — 50万元年度目标与持续研究主线

> 历史参考：当前方案与待办已合并至[策略研究与实施方案](plan.md)。下文保留原日期记录；“方案被替代”不代表功能已验收。

> 2026-09-13，规划v0.5；更新研究方案，不代表自动调优已部署或收益目标已验证。
> 固定：50万元、现金只做多、最多两只、上月完整自然月全A成交额Top20、每日提前计算。
> 本轮入口：本文 → [年度实验](annual_campaign.md) → [后台常驻任务](research_daemon.md)。

具体技术设计见[量化架构](quant_architecture.md)及[账户重演协议](replay_protocol.md)，均属于待实施能力。

## 1. 决策与目标

方向继续采用日频趋势波段；先解决有效回测和资金利用，再检验市场择时、入场结构与有限选参。
建设长期运行的研究任务：自动核验、排队、回测、归因、观察新数据；每轮参数搜索有明确边界。
已有数据支持基础研究，尚不能证明任何策略能够达到下列目标。

| 层次 | 50万元账户判定 | 与采用的关系 |
|---|---|---|
| 基础收益目标 | 指定年度成本后净收益 **>30%**，期末净资产 **>650000元** | 单独报告是否风险内达成 |
| 进取收益目标 | 指定年度成本后净收益 **≥100%**，期末净资产 **≥1000000元** | 不是强制放大风险的理由 |
| 研究有效性 | 账本正确、共同样本、稳定验证增量和完整试验记录 | 历史达标也不能跳过 |
| 持续使用资格 | 冻结政策通过时间验证，完成日批与执行观察 | 与某一年是否翻倍分开 |

分母包含未投入现金；不入金、不融资。总仓80%、单股40%、单股风险1%、合计2%、回撤10/15/20沿用研究默认。
30%和100%的月复合算术量级约2.21%和5.95%，不设置每月必须追回的盈利配额。
年内触及、期末保持、风险内达成和可变现余额分别报告；判断使用未按展示精度四舍五入的账本金额。
具体年度沿用已提交的2025-09-05～2026-09-04，不随查询日期滚动；见[年度协议](annual_campaign.md)。

## 3. 本次数据诊断带来的取舍

- 2026年8月与9月冻结Top20重合13只、换入7只：须量化离池退出对利润尾部和换股成本的影响。
- 截至09-11，按沪深300实际日期对齐，19只有60日完整价格窗口，688825.SH仅有35条行情。
- 19只的ATR/收盘中位数约5.48%，2.5ATR退出距离约13.71%；单股1%风险下静态权重中位数约7.29%。
- 若两只均取该中位风险，理论合计约14.59%，还未扣费用、最小申报量、市场和相关性限制。
- 当日19只均未满足完整趋势条件，纯量价入场为0；这是一日诊断，不是年度机会不足或策略失效的证明。

因此先跑M01全年机会/金额漏斗。每日评估可以解决错过评估日，无法解决所有股票趋势都不成立。
回踩结构有机会改善退出距离，但必须验证实际亏损、净R和机会数；不得压紧退出线只为增加股数。
截图式胜率、上限80%或两只各25万均不能替代真实资金使用；本次临时诊断也不属于正式推荐。

## 4. 策略与因子演进次序

| 顺序 | 对照与因子 | 要回答的问题 | 失败时的处理 |
|---|---|---|---|
| P0 | S0/S1；MA20/60、RS20、HC20、ATR、量能比 | 趋势整套政策是否胜过同风险基准？ | 先定位信号、执行或风险额度瓶颈 |
| P1 | S1→S2；指数T、全A宽度B、ΔB5 | 减少退潮损失是否覆盖错失行情？ | 同时报现金占比，不把少买当选股改善 |
| P1 | S2→F1；只改变盘后入场评估频率 | 新增机会扣费后是否正期望？ | 保留原频率，不叠加入场新条件 |
| P1 | F1→E2；回踩、缩量、转强、事前空间R | 能否改善买价及风险后可用仓位？ | 记录回踩失效、过滤损失与盈利尾部 |
| P1 | F1→E3；冻结突破位HC20失守 | 能否减少失败突破大亏？ | 同时报卖早损失和新增成本 |
| P2 | S2→E1、S2→S3；行业扩散、跌停压力、量能过热 | 能否减少两仓共同下跌与拥挤退潮？ | 历史关系/限价数据不足则只做观察 |
| P3 | 波动调整排序、换手分位、资金流和财务事件 | 相对现有量价是否有独立增量？ | 逐个登记；未有增益不进入交易 |

精确公式与点位沿用[factors](factors.md)、[levels](levels.md)、[experiments](experiments.md)，本轮不暗改阈值。
S0→S1同时改变入场/退出等政策，不能全部归因于选股；E2同时使用回踩形态和结构止损，只能先验证整体效果。
若要拆解E2的入场与退出贡献，须另立消融实验及预算，不能在当前167块里隐含增加组合。
RS20在同日减同一个指数，不改变个股动量排序；它不是新的风险中性选股能力。
“主线、分歧转强、退潮”分别转为行业扩散、E2和市场风险假设，日线无法验证盘口承接和排队成交。
中国市场动量/反转研究说明结果依赖观察、持有期及证券特征；这是做对照的理由，不是本账户的收益证据。[研究][momentum]

## 5. 参数和工程缺口

| 必补项 | 当前问题 | 约束 |
|---|---|---|
| 公平S0 | 当前默认退出距离固定8%，文档要求同口径ATR风险 | 修正基准并升级模型版本；保留旧结果，不冒充新alpha |
| 权益/交易规则 | 分红应收、到账、送转、税费、历史限价及资格未完整装配 | 不能靠复权比值猜分红；最小买量与递增量分开 |
| 参数入口 | BacktestReq无strategy_params，PrepareS0/S12使用DefaultParams | 先契约，白名单两维，完整配置/hash；不开放任意因子表达式 |
| 时间与目标 | API现有限366天/13月，只有一个target_multiple | 报告增加30%/100%两级判定；多段账户接续独立验收 |
| 调优治理 | 缺campaign、评分、预算、访问记录、候选采用 | 按[常驻任务](research_daemon.md)实施，不让LLM直接改交易参数 |
| 日批一致性 | 22:00冻结、固定数量条件计划、账户延续和发布待齐 | 正式年度证据绑定同一执行模型，旧回放结果不自动继承 |

已解释的上市前/停牌缺行不伪造为行情；持仓估值、待收权益和未知执行价仍走明确处理或阻断。
历史规则需要生效日及暂缓条款，不能全程套最新版本。[上交所规则及附件][sse]
