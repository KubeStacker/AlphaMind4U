## 1. 因子诊断必须针对真正的选股范围

- 主样本为每月当时冻结的原始Top20，按当时交易资格和信号所需历史过滤；不得用今天名单回推。
- 同时保留全市场诊断，仅作背景；全市场有效不等于Top20内能帮助选出两只。
- 对5/10/20日三个固定观察期，计算信号后首个交易日开盘至再过h日开盘的同尺度收益。
- 该收益是价格标签，不是可执行账户收益；涨停买不到、离池强制退出等另由账户模型处理。
- 缺失未来价格、停牌或退市要标记不可观测及原因；不得默默丢掉困难样本后只报完整者收益。
- 每个因子、月份和板块报告覆盖、分布、异常值、有效证券数和业务/可用时间差。

主结果不能仅显示理论标签；同步展示“通过所有执行约束的信号比例”和无效/受阻样本数量。
观测期限不等于策略持有期限，标签在因子诊断使用，不反过来决定当时买卖。

## 2. 单因子检查

| 检查 | 方法 | 解释限制 |
|---|---|---|
| 排序信息 | 每日Spearman Rank IC：因子与未来收益的秩相关 | 当日有效证券<10或常数因子时记不可估，不记0 |
| 分组收益 | 至少15只时分三组，按因子值排序、同值代码排序 | 仅20只不宜机械分十组 |
| 前两名增益 | 前两名相对当日可比Top20等权的后续收益与下跌幅度 | 只是选股诊断，随后必须验证50万实际账本 |
| 条件表现 | 按预定义市场状态、行业、波动和换手分组 | 不能看完测试结果再选择只保留某一状态 |
| 冗余 | 训练期逐日因子秩相关的中位数；绝对值≥0.8标记 | 不自动删除；检查是否只是同一趋势的不同写法 |
| 稳定性 | 按月份、板块、股票池更替分段，检查符号和集中度 | 大量日期高度相关，不等于大量独立样本 |

核心不设置“IC>0.03就采用”之类统一阈值；Top20小样本下须同时看区间、方向稳定和账户增量。
市场宽度、退出距离属于择时/风控变量，不用个股横截面IC评定它们是否有效。
风险因子应检验尾部损失、风险暴露与资金利用率，不能因它不预测涨幅就删掉。

## 3. 从因子到策略的增量验证

首轮8个版本按 experiments.md 比较；同一比较只改变声明的那一项。
行业/资金历史较短时，让基础版同时跑“全部可靠历史”和“增强共同可用历史”，分别展示。
逐月输出机会漏斗，保留每个过滤条件独立拒绝数及顺序过滤剩余数；重叠拒绝不能相加当总数。
同时输出金额漏斗：风险预算前后的目标资金、合法股数、名额占用、追价取消与最终成交额。

若增强收益较低但回撤改善，先报告现金占比和相同暴露下的诊断，防止把少买解释成选股能力。
若某条件几乎删掉全部机会，只记冲突或样本不足；不能在同一测试区间不断放宽直到获利。
每个run保存完整每日净值、所有意图和拒绝原因；不存在“只保留最佳两笔交易”的组合实验。

## 4. 样本外与统计不确定性

尽量覆盖至少5年可靠数据，按24个月训练、6个月验证、6个月测试，步长6个月向前推进。
有h日标签时，训练/验证末端标签必须已结束且公开；本轮最大20日标签至少预留21个交易日边界。
不随机打乱交易日；测试特征可以读取此前预热行情，但不能读取之后收益或修订信息。
固定版本默认跨折连续持仓、现金与回撤，不每折重置本金；折边界本身不触发买卖。
若未来采用训练期选参后的逐折换版，必须预先登记参数接管与旧持仓退出规则，不能直接拼接净值。
先交付固定参数回测；持续调优采用tuning.md的独立冻结政策，并验证整个选择流程。

可采用20交易日区块重采样，对同日期配对的策略收益差估计不确定区间，记录种子和方法。
这只是在保留部分时间相关性下的情景分析；不是未来概率，更不能把重叠一年窗口当独立试验。
严格区分过去一年回顾、开发中已观察区间、冻结后未见数据；历史滚动测试仍披露研究选择偏差。

## 5. 采用、保留和淘汰

| 结果 | 处置 |
|---|---|
| 未来信息、名单错误、虚构成交、费用缺段或持仓>2 | 结果无效；修正后新run，旧证据保留 |
| 缺可靠历史、有效信号过少 | 标为证据不足，继续采集或模拟，不宣称通过也不强行淘汰 |
| 增强在多数测试折无改善，且成本压力下优势消失 | 不升级；记录失败归因 |
| 正样本外收益、回撤≤20%，并有净超额或解释充分的风险改善 | 达到研究候选门槛，仍需执行模拟 |
| 一年成本后期末≥100万元 | 仅该实际窗口目标达成；另报是否依赖极少交易 |

升级证据默认至少包含4个6月测试段与50个完成持仓周期；不足可做技术模拟，不能认定收益验收。
一个周期指单股从首次建仓至完全退出，分批减仓不增加周期数；这些周期也不假定统计独立。
以上为项目最低证据门槛，不是统计充分性保证；行情阶段覆盖不足仍标记不足。
对少数大赢家敏感时披露删除最佳股票/月份后的结果，而不是把赢家删掉再当主绩效。

## 6. 实验预算与记录

第一轮8个固定版本；局部调优按tuning.md最多9组，后续周期登记预算、累计谱系和已访问区间。
每次尝试记录 hypothesis、parent_version、唯一改动、参数、数据/费用版本、指标、结论与弃用原因。
同时记录未运行、错误、失败与人工否决，禁止只保存赢者；候选数量本身影响研究可信度。
多次试验与回测过拟合的关系参见 [Bailey等原始论文][pbo]；本计划不输出未经计算的PBO/DSR数值。
2026-09-08已核验原文关于重复试验与选择偏差的论证；项目样本/预算初值不是论文保证。

成功率口径见review.md；年度目标须逐起点重演，不能仅切片连续净值替代新账户。
胜率样本、未平仓处理和不确定性补充见[win_rate_validation.md](win_rate_validation.md)。
研究阶段结果详表沿用 [validation.md](validation.md)，上线后监测与换版见 [evolution.md](evolution.md)。
