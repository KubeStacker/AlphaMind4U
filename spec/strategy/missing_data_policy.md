# missing_data_policy — 缺部分数据时如何继续交付

> 历史参考：当前方案与待办已合并至[策略研究与实施方案](plan.md)。下文保留原日期记录；“方案被替代”不代表功能已验收。

> 2026-09-09；有效实施规划。现有关键数据阻断继续生效，不授权静默填充或删样本。
> 目标仍是50万元、最多2只、前月全A成交额Top20、每日提前计算；年度翻倍是待验证结果。

## 1. 哪些可以完成

工程功能、调度、冻结快照、只读报告、账户状态、成交/权益账本和受限范围研究可继续开发。
缺数据日仍可按时发布阻断报告及原因，不等于发布有效买入计划；二者分开统计。
只有各启用策略及账户的必要依赖通过，才能验收该范围研究；不要求所有增强数据先齐备。
关键数据不齐时，不能验收原目标完整年度的真实收益或成功概率，也不能将全部规范归档。

## 2. 按依赖处理，不能只看缺失比例

| 缺失类型 | 可继续方式 | 不能做的处理 |
|---|---|---|
| 新闻、财务、资金流等未启用增强因子 | 基础版不依赖这些字段，功能和基准研究继续 | 把缺失填零作为真实中性信号 |
| 某分支必需的指数/宽度 | 该分支阻断；独立运行依赖已满足的基础版 | 将S2静默切成S1或把nil全现金当择时通过 |
| 个股指标窗口缺失但无账户权益暴露 | 预登记的受限变体可标候选不可用，不递补Top20外股票 | 跑完后才按盈亏挑要删除的证券/日期 |
| 与任何指标、排名、持仓和待收权益均无关的行 | 依赖审计证明无影响后可缩小读取与校验范围 | 仅因当前不持有就忽略其排名或未来窗口影响 |
| 全市场月成交额缺失 | 补数；或以可信上界证明缺失不影响Top20及排名顺序 | 只检查入选20只或用覆盖率阈值证明排名正确 |
| 成交价格、实际交易资格、交易日历未知 | 对应执行/研究阻断 | 工作日代替交易日、猜测成交、删除被困持仓 |
| 持仓或待收权益涉及复权/公司行动缺失 | 补权益来源；必要时停止绩效发布，保留状态与原因 | 因子填1、跨缺口插值、忽略分红/送股或假定已到账 |
| 已证实停牌且权益连续 | 可按预先规则保留旧估值并标陈旧，禁止假成交 | 未知缺行直接等同停牌，宣称陈旧净值可兑现 |

“可信上界”需来源或交易规则证据；没有上界就保持排名不可确定，不自行选一个金额上限。
指数仅有日线足够计算某些趋势，但不能自动替代全市场宽度或涨跌停情绪。
行业若参与硬约束就属于必要依赖；若只是尚未启用的增强假设，不能反过来卡住独立基础版。

## 3. 三类研究任务必须分开

1. 严格验证：满足该策略全部必要数据、时点、执行/费用和权益要求，才能进入完整研究验收。
2. 受限研究：事先固定缺失处理、有效范围和假设；保存独立版本，不能继承严格验证标签。
3. 工程回放：检验计算、序列、对账和页面；可以使用现有不完整研究底座，但不得宣称历史绩效已获验证。

严格模式新结果标为engineering_replay；显式可用候选模式标limited_research，不能将其混同为严格验证。
COMPLETED仅表示计算及现有检查完成；BLOCKED表示所需输入或检查未满足，均不代表策略采用状态。
旧run缺少证据字段时提示“未保存证据等级”，不能补写已通过验证。

## 4. 受限研究启用前必须补的机制

- 后台依赖审计输出：日期、证券、字段、缺失原因、受影响窗口/排名/持仓权益、来源及修复状态。
- 固定研究区间、原始Top20、缺失处理规则与模型；不依赖未来是否补齐或后续盈亏来选证券。
- 仅无权益暴露的候选可按预登记规则禁新增；原始20个名次保留，不从第21名替补。
- 不确定可能影响任一原排名时，该月不可认证；不能用最终入选股票的完整行情反证全市场完整。
- 同时报告预期/有效月份、候选不可用数、禁新增天数、未知估值和账户未完成周期，不隐藏空仓。
- 比较不同策略时使用共同合格区间及相同缺失规则；完整与受限结果分表，不混合排名。
- 不完整年度不能裁掉缺日后年化成一年；多个独立短区间不能拼接成连续50万账户。
- 必要的缺失相关性、下跌/波动期覆盖偏差与成本压力同时报告；受限收益不是原目标策略的收益。
- 后续补数另建run并对照，保留先前受限结果；不得在旧run上替换输入。

## 5. 接下来按两条线执行

工程线：必要依赖清单/审计 → 每日22:00冻结及阻断发布 → 账户延续/权益账本 → 条件计划和只读首屏。
数据线：恢复有效凭据 → 审计全年度及预热/排名月 → 定向回补 → 独立对账 → 共同样本基础策略比较。
两条线可独立推进，不把数据源凭据当作所有开发都必须停止的条件。
先完成基础策略，再考虑情绪增强；未满足基础证据前不通过扩大参数搜索弥补数据不足。

## 6. 验收边界

可先关闭具体工程子任务，必须链接其实际接口/回放/构建证据；整体T05/T06/T07仍逐项判断。
“每日都有状态报告”“计算完成率”“有有效交易计划的比例”分别统计，禁止共用一个成功率。
年度任务只有完整连续账户、必要来源/权益/执行规则和有效样本外验证齐备后，才报告目标达成证据。
未来收益无法作为工程完成承诺；目标未达到时如实记录，不通过改变分母宣布完成。

## 首个受限实现

新增显式data_policy=available_candidates，默认strict不变。仅逐日屏蔽缺失/非法量价行，不整只删除证券。
缺窗口不能产生信号；曾买入证券后续缺关键行仍阻断，因为持仓或潜在待收权益尚需核对。
报告缺行总量与最多100条明细样本，样本截断明确显示；全市场排名、时点与指数依赖并未豁免。
该模式是独立研究变体，不能承诺任何缺数都不影响一年结果，也不能让预测模块忽略关键输入。
