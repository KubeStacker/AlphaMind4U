## 3. 本地复现方式

临时用例位于`/tmp/jarvis_strategy_review_probe_test.go`，overlay位于`/tmp/jarvis_strategy_review_overlay.json`。
overlay把测试映射到strategy包的虚拟review_probe_test.go，不修改业务源文件或既有测试。

```sh
cd /root/jarvis/services/quant-backend
env GOCACHE=/tmp/jarvis-strategy-review-gocache go test ./...
env GOCACHE=/tmp/jarvis-strategy-review-gocache go vet ./...
env GOCACHE=/tmp/jarvis-strategy-review-gocache go test \
  -overlay /tmp/jarvis_strategy_review_overlay.json ./internal/strategy -run '^TestReview' -count=1 -v
```

第三条当前应非零退出；前端在frontend目录执行npm run build。
临时文件不作为永久交付依赖，修复任务须据上表固化正式回归，并保留输入和预期账本。
现有测试主要验证正常合成路径、排序、迁移往返和接口参数；其通过不能覆盖这些反例。
