# win_rate_validation — 怎样验证交易胜率与年度目标

> 历史参考：当前方案与待办已合并至[策略研究与实施方案](plan.md)。下文保留原日期记录；“方案被替代”不代表功能已验收。

> 2026-09-08；有效研究规范，待实施；没有本系统当前胜率或未来翻倍概率的估计。
> 与validation、factor_validation、tuning共同使用；新增指标不改变交易规则或搜索预算。

## 1. 先固定统计对象

| 对象 | 正确定义 | 不能代替什么 |
|---|---|---|
| 信号价格标签 | 当时合格候选的固定5/10/20日未来价格表现 | 不等于账户成交或交易胜率 |
| 成交率 | 已冻结且到执行窗口的买单中，有实际参考成交者占比 | 不等于选股正确率；未成交也须保留 |
| 交易胜率 | 净盈利的已完成持仓周期/全部已完成周期 | 不等于账户赚钱概率或年度翻倍率 |
| 净期望 | 全部完整周期的净盈亏及R收益分布 | 不能只报赢家的收益 |
| 年度达成比例 | 独立重建C0的有效12月账户中，期末达标的比例 | 重叠窗口比例不等于未来概率 |
| 年内触及比例 | 同一12月账户中，收盘净值曾达到目标的比例 | 不等于期末保住或已变现 |

一个周期从某证券首次建仓至完全退出；分批卖出、送转和代码变更不增加交易次数。
净盈亏合并全部成交、适用成本与公司行动；已确认未到账权益另列应收，不能漏计或重复计入。
已退出但权益金额/税费尚不能确定时标记会计未完结，不能先报赢；与仓位是否全平分开记录。
净盈利>0为赢，净亏损<0为输，净额为0单列平局并留在胜率分母；零交易胜率为不可估而非0%。
未完成周期不强行算赢或输，但必须报告数量、浮动盈亏、陈旧估值和被困天数，计入账户净值。
同时按首次入场月份展示成熟与未成熟周期，防止策略把亏损长期挂账而提高已平仓胜率。

## 2. 每次回测必须给出的交易质量表

| 指标 | 定义/用途 |
|---|---|
| N、赢/输/平、未完成数 | 样本数量和分母透明；分批退出不拆笔 |
| 胜率及不确定区间 | 同时报总样本与时间块，不能只显示百分数 |
| 平均盈利/亏损、盈亏比 | 分元、持仓收益率、初始R三种口径，不混用加权方式 |
| 平均/中位净R、R的下尾 | R分母固定为入场初始计划风险，不用期末抬高止损反算 |
| Profit Factor | 盈利周期净利润和/亏损周期净损失绝对值和；无亏损时标不可估 |
| 持仓时长、资金与名额占用 | 好机会是否被旧仓挤出、胜率是否用过长占用换得 |
| 入场后MAE/MFE、退出后路径 | 最大不利/有利变化及卖后5/10/20日诊断；禁止事后决定实际交易 |
| 受阻、跳空损失与费用 | 同时报因不可执行而取消的候选，不能只看成功成交 |
| 前5大盈利贡献、最差交易/组合日 | 显示集中度；总净利润≤0时贡献比例标无意义并报绝对金额 |

盈利与亏损均用成本后数据时，无平局的盈亏平衡胜率为`平均亏损/(平均盈利+平均亏损)`。
因此不能统一要求胜率>50%；是否值得采用要看账户净增长、风险与样本外证据。

## 3. 胜率提升怎样才算有证据

先给便于理解的Wilson 95%区间，再单独处理交易相关性；Wilson本身假设二项抽样模型。
例：40个独立周期赢24次，胜率60%，区间约44.6%～73.7%；200次赢120次约53.1%～66.5%。
这些是算术示例，不是Jarvis样本；同一行情中两只同主题交易往往不符合独立假设。[NIST方法][wilson]

研究默认按20交易日时间块估计不确定性，同时固定报告10/40日敏感性，不挑最好区间长度。
净值增量按相同日期配对，重采样时父版和候选使用相同日期块，保留两仓共同波动。
胜率统计按首次入场日期组织完整周期，同块的两只和重复交易一起抽取，不独立洗牌每笔。
持有跨块或时间依赖较长时，20日块未必充分；区间不稳定、有效块少时标记证据不足。
重采样不产生新市场历史，也不证明重排收益后的路径可按原账户状态执行；不能据此宣称未来翻倍概率。

声称“胜率提高”须同时满足：

1. 开发数据中事先登记唯一改动、主要指标、比较范围、分组和全部试验数。
2. 使用相同历史资格、费用、执行规则和账户限制，报告候选新增/删除的全部机会。
3. 在未用于选择该改动的数据中，报告胜率差、区间、每笔净R及账户增长差。
4. 策略交易集合不同时，不将第1笔与第1笔机械配对；时间块对照并解释样本组成变化。
5. 差异区间跨0只能称方向性观察；即使胜率提高，净增长恶化或尾部风险越界仍不能采用。

项目既有最低研究证据为4个6月测试段和50个完成周期；这是门槛，不是胜率精度的保证。
若未达到条件，可完成技术验证和未来观察，不能把样本少解释成高确定性。

## 4. 用诊断决定下一轮实验

| 发现 | 检验假设 | 需要同时比较 |
|---|---|---|
| 退潮期亏损多 | S2市场覆盖是否减少无效参与 | 相同暴露诊断、漏掉的盈利、净增长与回撤 |
| 高开买入随后回撤 | E2能否改善入场结构 | 真实成交位置、MAE、平均赢/亏、机会流失 |
| 多次小盈利抵不过大亏 | E3失败退出是否减小亏损尾部 | 跳空不能止住的部分、卖早损失、成本 |
| 周频遗漏转强 | F1是否提高有效机会数量 | 新增周期净期望，不能用更多交易数证明有效 |
| 两只同时亏损 | 行业/相关性信息是否改善组合 | 共同尾部、空仓代价、同约束的基准 |
| 胜率高但账户增长低 | 是否赢得小、持有久或实际低仓位 | R收益、年度周期数、资金/名额占用及目标缺口 |

先用既有市场状态分组；行业、波动、跳空档位需开发期登记，不能在终测上反复切片寻找高胜率小组。
分组过小、重叠过滤多或大量试验时，应降低结论强度；不自动训练一个综合“胜率评分”。
若以后输出概率，须有独立校准、可靠性图及Brier分数等验证；排序分数不得显示成胜率百分比。

## 5. 年度目标与验收证据

每个预登记月初重新投入50万，按当时可得政策运行12个月；另报连续运作轨迹，不能拼接最佳折。
逐窗口报告期末金额、首次触及日、目标短缺额、最大回撤、停用、费用、被困资产与完成周期。
短缺额分别为`max(0,650000−期末净资产)`与`max(0,1000000−期末净资产)`；另保存严格>30%及≥100%判定。
终值达成、风险内达成和年内触及分别计数；等于65万时距离为0但尚未严格超过30%，见annual_campaign。
有效亏损、全现金、超回撤与零交易都保留；缺失数据窗口单列，不使用缺数淘汰亏损期。
展示预期窗口数、有效数、无效原因、重叠程度及不重叠年度对照，历史比例旁不标“未来成功率”。
一次年度翻倍只证明那条已核验轨迹；是否能够推广，依赖独立样本与之后冻结版本的实际记录。
首次触及后的退出锁定属于策略变更；当前只报告，不自动改变买卖或让优化器挑触及日离场。

## 6. 可视化交付要求

- 一行并列：本金/净资产/目标缺口、交易胜率与N、盈亏比/净R、回撤、数据有效性。
- 胜率与盈亏比散点并排展示父版和候选；颜色标开发/未见数据，不能把各类证据混成一个排名。
- 净值、回撤、实际/允许仓位联动；标出20%停用、首次触及100万和期末状态。
- 用漏斗拆开信号、现金、最小量、名额、跳空拒绝；缺数据与行情无机会用不同状态。
- 月度/状态矩阵每格显示样本数和不确定性；低样本不使用暗示确定性的红绿强度。
- 3×3参数表保留所有格点与失败；年度窗口表标重叠，支持逐笔证据定位。

## 基础统计实施范围（2026-09-09）

首步统计只覆盖当前可运行的成交模型：按完全退出合并周期并计入成交价中的滑点及实际扣收费用。
未平仓周期净盈亏为null，零完成周期胜率为null，无亏损周期Profit Factor为null。
这些是研究模型描述统计；公司行动/历史费用/资格未验收，不代表已验证实盘胜率。
Wilson与时间块区间、净R及样本外增益尚未实施，不用单次点估计声称成功概率。
