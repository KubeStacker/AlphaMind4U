## 1. 四类配置分开保存

| 类别 | 内容 | 是否可作为收益寻优变量 |
|---|---|---|
| 账户情景 | 本金、现金保留、持仓金额上限、风险额度、权限、费用 | 可自由配置并做敏感性对照，不用自动放大风险取胜 |
| 策略参数 | 突破周期、跟踪退出倍数等有限旋钮 | 仅在tuning.md声明的离散空间内搜索 |
| 研究设计 | 起止日、开发/验证/测试边界、目标、搜索预算 | 提交前冻结，改变产生新的实验设计 |
| 数据与执行 | 数据快照、交易规则、滑点情景、成交模型 | 版本化；不能把错误成本当可优化参数 |

每次运行的完整配置不可变；页面编辑仅改草稿，保存情景/显式提交研究后才生效，不修改历史结果。
最多持仓数可选1或2；上月全A成交额Top20、无杠杆仍为本任务边界，不能通过配置绕过。

## 2. 账户字段与默认值

| 字段 | 默认 | 定义 |
|---|---|---|
| initial_capital C0 | 500000元 | 期初账户现金；不包含未划入账户的其他资产 |
| gross_cap_mode | nav_fraction | nav_fraction / fixed_amount / both，明确复投或固定额度 |
| gross_cap_ratio u | 0.80 | 股票总市值占当时完整净资产上限 |
| gross_cap_amount Amax | 未设置 | 股票总市值绝对金额上限，不是累计买入额 |
| cash_reserve_amount R | 0元 | 必须保留的现金金额，不借给股票预算 |
| single_cap_ratio | 0.40 | 单股占净资产上限，与总额度、风险取更严格者 |
| single_cap_amount | 未设置 | 单股市值绝对金额上限 |
| position_count | 2 | 未退出旧仓、零股、暂停交易证券都占名额 |
| single_risk_ratio / amount | 0.01 / 未设置 | 到退出线的计划损失限额，同时设置取较小值 |
| total_risk_ratio / amount | 0.02 / 未设置 | 所有持仓计划退出损失合计限额 |
| dd_reduce / freeze / halt | 0.10 / 0.15 / 0.20 | 相对历史最高净值的处置阈值，须严格递增 |
| capital_loss_limit_amount | 未设置 | 相对C0的累计净资产损失触发额，独立于最大回撤 |
| target_mode / multiple | multiple / 2 | 或选择fixed_terminal_amount，二者互斥 |
| target_terminal_amount | 派生1000000元 | multiple模式随C0计算；固定金额模式不自动改变 |
| cumulative_buy_limit | 未启用 | 累计买入额度不等于持仓额度，首版仅统计不限制 |

比例取0～1有限数；C0>0，0≤R<C0，金额以分保存，禁止负值、NaN、无穷大和非法精度。
固定金额模式须填Amax；同时启用金额与比例约束时取更严格者，不能同时显示“可满仓”和固定额度。
若输入单股上限高于总上限，展示实际受总上限约束，不默默改用户输入。
固定目标≤C0时标记“期初已达成”，不作为策略获胜或优化目标；风险触发金额须为正数或未设置。
风险阈值输入是研究情景，不是实盘风险授权；不同风险情景的收益不能混成同一排名。

## 3. 预算公式与分母

令E为完整账户净资产，X为当前股票市值，Cash为已到账可用现金，p为市场/回撤允许比例。
按所选模式令 `B_user=u×E`、`B_user=Amax`，或 `B_user=min(u×E,Amax)`。
`股票目标总预算 B=min(B_user,p×E,max(0,E-R))`，还要应用行业、相关性和单股限制。
`新买可用金额≤min(max(0,B-X), max(0,Cash-R-预留费用))`；到账和名额遵守execution.md。
账户单股计划风险预算取比例×E与可选绝对风险金额的较小值；组合风险同理。
相对C0亏损达到capital_loss_limit_amount时生成停用/退出意图，该次运行不自动重启。

上述均是目标或触发，跳空/停牌可能导致实际超限；现金负数和第三只持仓则是账本错误。
金额上限包含股价上涨形成的市值，超过则按规则生成减仓；若想限制买入本金须另定义字段。
R从可投资预算中扣除，但仍属于账户资产；账户收益 `(E_T-C0)/C0` 不扣掉R或未投入现金。
实际投入部分的收益可辅助展示，但不能用它代替账户收益或判断翻倍。

例：C0=50万、R=5万、u=80%、Amax=30万、模式both，市场允许80%时B最高30万元。
期末E=60万，账户收益为20%；不能用盈利10万/额度30万宣称账户收益33.3%。
当E增长到70万，fixed_amount/both仍受30万限制，nav_fraction模式可随净资产增长，必须区分。

## 4. 账户情景比较

日常账户配置保存后按[daily_batch.md](daily_batch.md)返回的决策批次生效，截止后修改不重算已发布结果。
临时资金研究进入后台队列，完成后读取新结果；输入任意本金不意味着查询时自动补算或穷举预计算。
默认展示目标情景50万；可选10万、50万、100万等自定义本金，以及不同持仓/风险额度。
本金和额度每批最多9个预登记情景；不是让优化器寻找“哪个本金能产生最好收益率”。
同一策略在每个情景重放股数、最低佣金、现金、交易容量、两只名额、公司行动和风控。
只能复用相同版本的排名、价格、因子与不依赖账户的候选信号，不能复用成交结果按倍数放大。
改变最大回撤、计划风险或是否复投时，界面明确标注风险/资金情景不同，不作同风险优劣结论。

模型调优只针对一个预先选定的目标情景；其余情景作冻结后的敏感性检查。
目标账户可由用户重新选择，但这会产生新实验，之前已看的测试结果仍保留已访问状态。

## 5. 运行前校验与可解释结果

运行前输出：有效数据区间、字段/规则缺口、初始可投入金额、合法最小买量、预计任务数与配置差异。
账户无任何可买股票时允许得到“全现金/无可执行机会”的研究结果，不自动加杠杆或扩池。
快照包括account_config_hash、strategy_config_hash、execution_hash、dataset_version和目标定义。
报告同时显示输入上限、实际生效上限、实际仓位与绑定约束；区分风险额度和仓位金额。
未来这些是待写契约字段，不是当前已有API；本次不创建账户或真实订单。

2026-09-09：runner开始前校验现有AccountConfig的有限数、模式、金额、比例及回撤范围。
固定金额/both必须有正额度；回撤阈值满足0≤reduce<freeze<halt≤1，目标倍数须为正有限数。
该早期步骤当时仅接内部回撤；后续已有AccountConfig字段贯通HTTP，剩余金额精度与扩展字段见下。

执行预算补修：买单冻结信号日市场/回撤上限market_cap，执行时不借用当日收盘状态扩大预算。
开盘以当前持仓估值、预计扣费后净资产和冻结上限重算总预算，结合单股/组合风险拒绝超限订单。
当批累计买入含佣金不得超过卖出执行前现金减CashReserve，不用当日卖出释放额绕过保留现金。
open_intents回显market_cap用于核对，卖单该字段为0且不参与买入预算；现有账户字段已随后开放HTTP。

账户接口补修：BacktestReq.account可覆盖现有AccountConfig字段，省略字段沿用默认值；null等同默认账户。
未知请求字段拒绝，配置校验先于加载/重放；响应account回显实际生效配置，收益分母使用initial_capital。
仅开放现有字段，不接受尚未实现的绝对风险、单股金额或固定目标字段；默认仍为50万元、最多两只。
