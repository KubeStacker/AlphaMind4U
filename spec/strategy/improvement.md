## 1. 每轮改善闭环

`收集证据 → 定位原因 → 提出可证伪假设 → 登记唯一改动 → 公平对照 → 采用/保留/撤回`

1. 证据来自数据审计、机会漏斗、全部交易、模拟偏差或运行监测，不能只收集成功案例。
2. 区分数据错误、执行错误、策略无效、资金约束和样本不足；它们需要不同处置。
3. 写明改动预计改善什么，以及可能牺牲什么；例如少止损也可能错失大行情。
4. 先固定比较区间、父版本、费用和其他参数，再计算结果；改动须计入实验预算。
5. 没有增量就撤回；证据不足就继续观察，不把“尚未失败”当改善成功。
6. 改善通过后仍走 evolution.md 的影子推荐和版本接管，不立即替换实际账户规则。

数据或成交模型错误必须修正，旧绩效标记无效；不能把消除错误包装成alpha提升。

## 2. 问题、改善方法与验收

| 问题 | 先看什么证据 | 优先改善动作 | 比较指标 |
|---|---|---|---|
| 数据看似完整却算不出因子 | 窗口、预期分母、错误返回、字段单位 | 修分页/状态/缺失语义，补必要历史 | 可复算月份、不可用原因、源站对账差异 |
| 多层门槛后几乎没有机会 | 每层拒绝数与交集、0/1/2持仓天数 | 先做冗余诊断；下一轮仅移除一个重复条件 | 有效机会、风险调整后收益与假突破损失 |
| 每周信号错过行情 | 每日触发在周末是否已消失 | F1只改每日评估 | 新增机会、换手、成本及净值差 |
| 突破后经常回撤 | 入场后最大不利变动、跳空幅度、量能分布 | E2回踩与E3失败退出分别比较 | 初始风险单位下的损失、错失上涨和交易成本 |
| 涨幅排序选到高风险股 | MOM20与β/σ/ATR%关系、前两名尾部 | 单独比较波动调整或残差排序 | 相同预算下前两名增量与共同亏损 |
| 两只来自同一主题 | 历史行业、ρ60、共同公告和受困天数 | E1信息与集中度分别验证，不先加重行业仓位 | 行业贡献、尾部损失、空仓代价 |
| 仓位长期低于预期 | 退出距离、整手、费用和组合上限的金额漏斗 | 检验更好入场位置；仍不足则报告目标矛盾 | 可投金额、净收益、退出失效率 |
| 频繁止损后原股上涨 | 完整交易路径与冷却期间表现 | 预登记ATR/冷却单变量研究，保持原版对照 | 减少的损失、新增损失、错失收益 |
| 盈利仓过早卖出 | 卖后5/10/20日路径、离池原因 | 先区分跟踪退出与月度离池约束 | 放宽退出的回撤代价，不擅自突破离池规则 |
| 因子有效但实盘近似无效 | 拒单、滑点、换股等待和最低佣金 | 先校准执行，不新增因子 | 回测/模拟差异、成交率和成本后增量 |
| 财务与新闻指标不稳定 | 公告时点、修订、预期基准、行业差异 | 补版本与预期证据，暂保留人工可核验解释 | 覆盖、时间正确性、价格外增量 |

“受困”包括停牌或无法按模型卖出；改善不能假定旧仓已清除，再把资金投入新赢家。
最大有利/不利变动可用事后路径作诊断，绝不能反过来决定当时实际成交价格。

## 3. 先做减法，再考虑增加信息

- 先审计同源性：RS20和MOM20排序相同；MA、突破、趋势效率可能携带重叠信息。
- 先检查时间尺度：5日回踩、20日趋势、每周评估之间是否匹配，不能同时换频率和持有规则。
- 先检查约束叠加：市场上限、行业上限、相关性上限和1%风险预算分别减少了多少资金。
- 再增加有独立来源的信息：可靠行业扩散、换手拥挤、公告前预期；每次只改一个环节。
- 新增MACD/RSI等变换不天然增加信息；必须证明在现有条件之外改善选择或执行。

这些诊断本身不改变主策略；任何移除条件或调整阈值仍须登记版本并消耗试验预算。

## 4. 改善提案模板

| 字段 | 必填内容 |
|---|---|
| 问题编号与证据 | 来源日期、样本范围、完整反例，不填未经运行的收益数字 |
| 父版本与唯一改动 | 例如S2改每日评估；其余因素固定 |
| 原因假设与反证 | 解释为何有效，以及什么结果会推翻假设 |
| 数据依赖 | 字段、历史范围、可用时点、缺失与单位 |
| 主要指标与代价 | 一个主要改善指标，加回撤、成本、资金使用率和机会损失 |
| 样本与实验预算 | 训练/验证/测试边界、尝试编号、已看过的数据 |
| 采用门槛与回退 | validation与factor_validation门槛，失败后如何恢复父版本 |
| 结论 | 采用候选、继续观察、否决或数据无效；附全部run引用 |

示例假设：周频遗漏转强机会。对照S2与F1，唯一改变入场评估频率，保持两只和风险预算。
若增加的净收益不足以覆盖成本与更大回撤，或只来自一个月份，则不升级；本例没有回测结果。

## 5. 改善工作的优先级

P0：数据与账本真实性，包括仍存在的任务吞错路径、月排名完整性、法定费用和两只不变量。
P1：S0/S1/S2/F1的机会与资金漏斗，确认主要瓶颈；再检验E1/E2/E3及已就绪的S3。
P2：根据已观察失败类型，按tuning.md选择一个家族、最多两维9组；不扩展为全参数搜索。
P3：只有既有框架仍存在可解释的信息缺口，才投入财报版本、历史预期或更细成交数据。

每周解决数据/执行偏差，每月整理研究问题，每季度决定是否开启下一轮有限实验。
突发严重数据或账本错误立即处理，不等季度；长期无独立增益的功能应退役，减少维护成本。
研究改善成功不等于翻倍成功，前者看增量证据，后者必须由成本后账户轨迹实际达到。
