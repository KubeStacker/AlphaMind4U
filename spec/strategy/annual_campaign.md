## 1. 冻结年度与结果定义

W0固定为2025-09-05～2026-09-04，沿用实际年度任务请求；替代旧文档09-06～09-06的展示边界。
起止日均由正式交易日历校验；账户以50万现金、零持仓开始，因子预热不产生起点前账户交易。
effect_months覆盖2025-09至2026-09共13月，排名从2025-08全市场开始；不得用当前Top20回测整年。
W0已被研究过程访问，属于回顾/开发展示；其结果不能冒充新假设的独立样本外证据。
目标年份可在新任务登记时指定；已运行后不能挪动起止日、挑最佳12个月来改变本任务结论。

令E为包含现金、持股、应收权益并扣除应计负债及真实费用的账户净资产，`R=E_end/C0−1`。

| 字段语义 | 定义 |
|---|---|
| 超过30% | R>0.30，即E_end>650000；正好650000不通过严格门槛 |
| 达到100% | R≥1.00，即E_end≥1000000 |
| 年内触及 | 分别记录首个收盘净资产越过650000、达到1000000的日期 |
| 目标距离 | 距离金额max(0,目标金额−E_end)，同时保存是否通过比较符，不能仅看距离为0 |
| 风险内达成 | 对应期末目标通过、全程账户规则有效、最大回撤≤20%；停用触发与受困单列 |
| 可变现情景 | 扣后续卖出费税并考虑受阻交易；非实际成交不能称已实现或可提现 |

目标不改变买卖。若研究触及后退出锁定，须另立假设；不能事后把高点作为退出日。
当前target_multiple=2仍保持；30%是同一账本的新增报告门槛，不必复制两个交易run。
佣金/滑点用冻结情景，法定费用及分红税按适用时间；未投入现金不从分母剔除。

## 2. 运行准入与公平基准

M00先发布用途矩阵：全市场月度金额排名、日历、历史资格、原价/因子、权益、限价、费用和来源时点。
数据政策冻结；539条已解释缺行仍保留原因。新缺口不能按收益好坏排除证券、月份或亏损交易。
增强输入缺失可阻断对应分支；关键账户权益缺失不能降级为无事件，不能用部分净值参与收益排名。
行情历史修订与最新概念禁止穿越；历史下载没有当时快照时明确标记“事后重建的时间代理”。

比较S0/S1/S2/F1；S3/E1/E2/E3仅在实现及依赖验收后列入预登记8版，不为凑数运行空壳。
S0当前固定8%退出须改为文档约定的同口径ATR风险后才是公平对照；同时验证费用、权限和数量模型。
执行保持盘后信号、下一可执行时点、T+1、真实涨跌停/停牌、受阻旧仓占名额，不能日内理想成交。
正式目标模型采用[daily_batch](daily_batch.md)的事前固定数量条件计划；旧执行模型另标技术结果。
现金、沪深300口径明确的指数收益、Top20理论等权仅作诊断；随机两只固定种子0～19且运行全部。
20只理论等权不满足两只持仓约束；收益较高不能替代账户结果。

## 3. 历史滚动验证方案

候选范围为2022-03～2026-08，先审计每个实际依赖；日线最早年份不能证明该范围全部可用。
每折前30个月开发、后6个月评估；开发内第13～18、19～24、25～30个月为3个验证块。
参数候选在这18个月连续重演，只输出3段统计，不每段重置现金、持仓、冷却及回撤。

| 折 | 开发30个月 | 外层6个月 |
|---|---|---|
| WF1 | 2022-03-01～2024-08-31 | 2024-09-01～2025-02-28 |
| WF2 | 2022-09-01～2025-02-28 | 2025-03-01～2025-08-31 |
| WF3 | 2023-03-01～2025-08-31 | 2025-09-01～2026-02-28 |
| WF4 | 2023-09-01～2026-02-28 | 2026-03-01～2026-08-31 |

WF1开发区的2023-09～2024-08先做8个固定版本比较；过滤无效、风险越界及无正收益版本，按年度成本后对数增长排序。
首轮可寻优只限S2、F1或F1+E2之一；其他为基准/固定增强对照。无合格家族或不能改善S0则不启动9格。
增长差≤0.01/年时先保留已通过父版，再优先低换手、较少规则，最终按预登记版本顺序打破平局。
该家族及选择政策在四折中固定；每折只使用当时开发数据选参数，不按外层或W0期末赢家反选家族。
实际已看到的行情/图表均登记访问，以上只称“按时间复演”，不能因为划了外层就声称研究者未见。
历史不足时先保留W0与较短诊断，四折标未完成；不得缩小样本后仍声称达到4段证据门槛。
未来真正未见区间从候选冻结后开始积累；不能追认今日以前的数据为从未访问。

外层账户跨4折连续接续；新参数只用于新的意图，旧持仓沿来源版本退出，所有版本共用两只名额。
回撤停用不因换折解除；分别验证自适应政策、固定父版、S0三条完整轨迹，不拼接各折赢家。
5/10/20日因子标签须在切分前成熟，沿用21交易日保守隔离；纯因子预热不能读取未来价格。
当前API限366天/13月，不能把多个重置50万的run拼成上述轨迹；须先实现完整状态接续和分段验收。

## 4. 局部空间、评分与停更

突破家族：breakout_n={15,20,25} × trail_atr={2,2.5,3}，初始退出固定2.5ATR。
只有选择E2家族时，改用pullback_days={3,5,8} × min_space_R={1.5,2,2.5}；本轮不同时搜索两个家族。
其余指标、账户、本金、风险、费用、日期及目标均冻结；开关/排序替换是新的假设，不是隐藏第三维。
先过滤数据/账本无效和风险越界格点，再比较3个验证块成本后年化对数增长中位数G。
每块`G_b=365.25/d×ln(E_end/E_before_block)`，d为登记块起止自然日含首尾的天数，G取三块中位数。
E_before_block为块内首笔事件前账户净资产，休市不产生交易；全18个月高水位和风险状态接续。
同时展示最差块、交易周期、现金与费用；全现金G=0可有效完成，但不能据零交易认定有选股优势。
稳定区域沿用[tuning](tuning.md)：至少2个上下左右有效邻居，G差≤0.01/年；这是项目初值而非显著性标准。
近似持平优先原版、低换手和少改动；无增益、孤峰、样本不足或预算耗尽输出“不更新”。
30%/100%达成率、胜率和最佳年度不作单一寻优目标；不因未达标扩大网格或缩小步长。
保留完整试验数和谱系；重复查看同一历史后再改规则会增加选择偏差。[回测过拟合研究][pbo]

## 5. 可排队的首轮预算

下面是全部依赖通过时的预算上限；不可用版本保留NOT_RUN原因，不临时换成别的策略。
计算块是≤12个月的预算工作单元，18个月路径拆两块但不重置状态；内部可再分≤30秒安全片段，逻辑路径和块数同时保存。

| 工作 | 计算块上限 |
|---|---:|
| 首个开发区家族对照：8固定版×1年×正常执行 | 8 |
| 四折9格：4×9×18月连续验证路径，每条2块 | 72 |
| 外层：自适应/固定父版/S0×4折×3执行情景 | 36 |
| W0展示：S0/S1/S2/F1/冻结候选×正常及2项压力 | 15 |
| W0随机两只：20种子×正常执行 | 20 |
| W0现金/指数/Top20理论等权诊断 | 3 |
| 年度重新起投：2024-09～2025-09共13个月初×冻结政策×正常执行 | 13 |
| 合计 | **167** |

两项压力分别为佣金与滑点翻倍、买入延迟1交易日；税费依法定版本，不随压力翻倍。
延迟保留原数量/价区间，只顺延允许执行日期并重验有效性，不能重新选股；细则见[重演协议](replay_protocol.md)。
W0的最终候选整年固定参数回顾属于事后展示；13个起点使用各时点可得政策，不能回填最后赢家。
13个年度账户各自从50万重建；与连续轨迹滚动切片分开，重叠窗口比例不解释为未来成功概率。
选参由统一50万参考研究账户的开发回演产生，各起点沿用当时已冻结参数表，不根据自身期末收益重新挑参。
167是计划量，不是已完成数量；若依赖还需更多块或执行压力，提交前重算，上限200且不得静默删失败场景。
冻结输入相同的缓存复用可省计算，但计划和统计谱系仍保留；重试、改数据及跨批消耗分别累计。
先批量登记计划、逐项释放到现有队列，不能一次向当前最多20个活动任务的入口塞167项。
压力中另报告跳空/连续跌停、两仓同跌；移除最大贡献股票/月份仅作归因，不能替换主结果或重新选参。

## 6. 必交结果和采用规则

每条路径：manifest、输入引用、代码/参数/费用/规则版本、净值/回撤/现金、意图/拒绝/成交、权益/周期、漏斗。
结果同时保存执行状态、有效性等级、30%/100%判定；COMPLETED且亏损仍是完整结果，不删除。
净R/胜率按完整持仓周期统计，未平仓浮亏与应收权益单列；不能把某一日的20只当20笔交易。
差异按共同日期配对，20交易日块估计区间，固定报告10/40日敏感性；方法见[胜率验证](win_rate_validation.md)。
多次试验修正可后续增加DSR/PBO诊断，须有真实试验矩阵与适用假设；这些数值不是目标成功概率。[DSR原文][dsr]
候选采用仍要求至少4个6月段、50个完成周期、正成本后净收益及相对基准的收益/风险增益，具体沿用factor_validation。
跨折只有全部前置状态成功保存才可继续；某折失败则依赖折标未运行，不能跳过再拼接净值。
少于该门槛可以技术观察，不能宣称收益验收；20日影子运行只验执行，年度证据持续积累。
若W0达到30%但未翻倍，如实保留基础目标达成；若W0翻倍但样本外失效，仍不采用。
