## 1. 时间、单位和状态

`t` 为信号交易日，`C/O/H/L` 为同一复权尺度价格，`A` 为统一到元的原始成交额。
`r_t=C_t/C_(t-1)-1`；`mean_n(x,t)` 包含 t，`prevmean_n(x,t)` 为 t-n 至 t-1。
收益、换手和占比内部采用小数，界面显示百分数；金额单位必须从字段字典转换。
A：已有字段可派生但未验收；B：有部分数据，增强实验须补齐；C：当前缺必要来源或历史版本。
默认不对 20 只样本拟合多因子权重；不把每个因子都作为必须同时通过的门槛。

## 2. 量价核心与候补

| 因子 | 公式/方向假设 | 用途与状态 |
|---|---|---|
| MOM20/60 | `C_t/C_(t-n)-1`，正值表明上涨 | 动量诊断 A；20 日进入核心，60 日先观察 |
| RS20 | `MOM20_i-MOM20_沪深300` | 核心资格 >0、降序排序 A |
| 趋势结构 | `C>MA20>MA60`；斜率 `MA20_t/MA20_(t-5)-1` | 趋势门槛 A，不再当独立加分项 |
| 突破幅度 BR20 | `(C_t-HC20_t)/ATR20_t`；HC20 不含 t | 核心触发 >0；实际最高价 H20 单独保存 A |
| 量能比 AR20 | `A_t/prevmean_20(A,t)` | 核心区间 1.2～2.5 A，过大不自动视为利好 |
| 均线偏离 EXT20 | `(C_t-MA20_t)/ATR20_t` | 核心避免追高 A；突破上限3，E2上限2 |
| 趋势效率 ER20 | `abs(C_t-C_(t-20))/sum(abs(ΔC),20)` | 区分持续与反复震荡 A，先诊断不设入场阈值 |
| 收盘位置 CLV | `(C-L)/(H-L)`；H=L 则缺失 | 日线收盘强弱 A，不冒充盘口承接 |
| 换手拥挤 TP252 | 此前252日 turnover_rate_f ≤今日值的数量/252 | 换手 B；高分位可能过热，方向待检验 |
| 金额持续性 AP5 | `mean_5(A,t)/prevmean_20(A,t)` | 持续活跃诊断 A，与单日量能比检查冗余 |

同一时点所有股票减去同一个指数收益，RS20 的横截面顺序与 MOM20 完全相同。
RS20 >0 有资格过滤作用，但不是风险调整后的超额；不能与 MOM20 双重加权“增强信号”。
金额绝对值、换手率和主动买卖分类是不同概念；不以高成交额直接推断高换手或净流入。
ER、CLV、AP5、TP252 未进入首轮买卖规则；TP252 缺自由流通换手时不静默替换另一口径。

## 3. 市场、行业和风格

| 因子 | 定义 | 角色与状态 |
|---|---|---|
| 指数 T | 沪深300 C>MA60 且 MA20 五日斜率>0 | S2 市场状态 A |
| 宽度 B / ΔB5 | 可交易、连续20日行情完整者中 C>MA20 的比例及五日变化 | S2 市场状态 A |
| 市场成交 V | 全 A 当日金额 / 此前20日市场金额均值 | S3 过热观察 A |
| 行业超额 IR20 | 剔除候选自身的行业20日复合收益减沪深300 | E1 行业门槛 B |
| 行业宽度 IB20 | 同一历史有效行业、剔除自身后 C>MA20 比例 | E1 扩散门槛 B |
| 行业成交份额 IS | 剔除自身的行业成交额 / 同样剔除自身的全 A 成交额 | E1 与此前20日均值比较 B |
| 风格差 | 创业板指20日收益减沪深300，另报全 A 等权收益 | 诊断 A，不新增择时分支 |

行业成分需按 in_date/out_date 的源语义还原有效区间；处理更名、分类版本和重复归属。
IR20 每日按当时成分计算有效日收益等权均值，再复合；它是行业代理，不是可执行行业组合。
每个相关日需至少10个剔除自身后的有效成员、预期成分收益覆盖≥95%，否则该行业因子不可用。
B的分母不是Top20，也不按个人板块权限过滤；v0.3剔除历史ST、退市整理、停牌及历史不足者。
同时输出全市场应有数、有效数和排除原因；D使用普通A股的适用涨跌停价样本，不能只报占比。
原始金额/宽度口径及行业覆盖门槛不同，不能复用服务 complete 标志代替策略质量门槛。

## 4. 风险与交易可行性因子

| 因子 | 定义 | 使用方式 |
|---|---|---|
| ATR20 / ATR% | TR=max(H-L, abs(H-Cprev), abs(L-Cprev))；mean20(TR)/C | 核心退出与股数预算 A |
| σ20 | 20日复权日收益样本标准差 | 波动诊断 A；年化展示乘 sqrt(252) |
| β60 | 60日个股收益对沪深300收益含截距 OLS 斜率 | 风险暴露诊断 A，非收益保证 |
| 相关性 ρ60 | 同期60个完整日收益的 Pearson 相关系数 | 两只合计上限控制 A；缺失按同组处理 |
| 最小交易风险 | 合法最小买量 × (预计买价-退出线)＋预留费用 | 必须满足单股风险预算；规则数据 B |
| 开盘偏离 GAP | 次日原始开盘/公司行动校正后的信号收盘-1 | 执行检查，不能提前加入 t 日选股 |
| 持仓至退出线风险 | 正距离×当前总股数＋预留退出费用 | 存量减仓检查；跳空与无法卖出另报 |

β60/ρ60 至少需要61个连续收盘点，MA60只需要60个；不能用统一60条记录判断全部预热完成。
分母为零、价格非法或缺因子均返回缺失原因，不给出无穷大、默认0或完美相关性。
波动调整动量候补为 `MOM20/σ20`，会改变低波动偏好，须与风险定仓作用分开归因。
残差动量候补：每天用此前60日拟合 `r_i=a+β*r_m+e`，求过去20日事前残差之和。
最少需要81个连续收盘点；残差不是行业中性或已证明的 alpha，相关实验在第二轮登记。

## 5. 情绪、资金和财务增强

| 因子 | 定义/证据要求 | 状态与采用顺序 |
|---|---|---|
| 跌停压力 D | 当日有效涨跌停价适用样本中，收盘等于跌停价的比例 | C，S3 前置；按价格最小单位比较 |
| 昨强溢价 UP1 | 昨日涨停名单今天复权收盘收益等权均值 | C，先诊断；名单不能用今天结果筛选 |
| 炸板率 FB | 当日触及涨停却未封住的数量 / 全部触及涨停数量 | C，确认分类与板块覆盖；非封单质量 |
| 资金流 MF5 | 五日 net_mf_amount 折元合计 / 五日 A 合计 | B；检验价格以外增益，不代表机构身份 |
| 两融变化 RZ5 | 最新可用融资余额/五个业务交易日前余额-1 | B；记录业务日期与可用日期，不假定当日可得 |
| 营收、利润增长 | 同期同口径报表值的同比；上期≤0时单列扭亏，禁止强算增长率 | C，先补财报版本 |
| 现金盈利质量 | 同期经营现金净流量/净利润，净利润≤0时单列 | C，金融与非金融不能统一阈值 |
| 估值与超预期 | 行业内估值分位；实际值减公告前一致预期 | B/C；无历史预期不构造“超预期”因子 |

UP1 不等于从昨日涨停价一定可以买到的交易收益；停牌继续估值、缺失与不可买分别报告。
只有当日已发布、入库并通过校验的记录才能消费；两融延迟和财务修订不能向历史回填。
当前未保存 daily_basic 的非默认 limit_status 字段，不能因源文档存在就认为本库已具备。
