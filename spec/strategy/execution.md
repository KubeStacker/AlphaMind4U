# execution — 可重演的日频账户与订单规则

> 历史参考：当前方案与待办已合并至[策略研究与实施方案](plan.md)。下文保留原日期记录；“方案被替代”不代表功能已验收。

> v0.4执行规范；2026-09-07已有日线回放原型，事件时序、价格和受阻退出仍未通过验收。
> 实施状态：部分实现/验收阻断，不可归档；见[status.md](status.md)。

## 1. 数据时钟与预热

1. 使用沪深北正式交易日历，共同决策日按全 A 市场交易日推进；特殊差异逐证券处理。
2. 当日22:00冻结已通过质量门槛的数据；晚到或修订数据只影响后续快照，不倒改该日意图。
3. 行情取截至t的数据，前高/前低/成交额均值按各公式决定是否排除t，不统一shift整个特征表。
4. 新买要求核心入场因子所需的最近市场交易日窗口连续完整；停牌或缺失不压缩成更早的N条交易记录。
5. 新股没有足够窗口就跳过；相关性额外需61个收盘点，缺失时按组合保守规则，不伪造相关系数。
6. 复权因子、价格和公司行动使用同一快照；历史滚动尺度变化时，持仓退出线同步换算。

回测起点前可预热市场特征和状态，账户仍从配置C0与零持仓开始，不继承另一账户的高水位或仓位。
2026-09-08确认日常结果由[daily_batch.md](daily_batch.md)的固定批次产出；查询不重算策略或股数。

已确认停牌：持仓采用最后可用原始价并处理适用公司行动，标记陈旧天数，不新增买入。
未解释行情缺失：不得当停牌或无损失；记录区间不完整，该区间不能通过正式绩效验收。
停牌期间不虚构MA穿越；保留已有风险退出意图，复牌按最新可用价执行并披露跳空。
若无法计算存量所需退出指标，禁止新增并生成数据风险退出意图，等待可执行时点。
证券代码变更按稳定证券身份衔接，不把代码变化当卖出盈利、重新上市或新增持仓名额。

## 2. 每日事件顺序

- 开盘前：依据已知公司行动调整股数、价位与可卖量，确认现金到账日和证券权限。
- 开盘参考窗口：执行上一决策时点的卖出意图；再处理事先合格的新买，风险意图优先。
- 新买只使用上日已可用现金和空余名额；本次开盘卖出才释放的现金/名额不假定同价再买得到。
- 依赖本次卖出回款或名额的换股，最早下一交易日且重新形成有效信号后执行。
- 收盘：逐证券估值、核算费用与权益，更新历史最高净值、回撤状态和退出线。
- 22:00：在本版本允许的入场评估日计算新买，每日计算卖出和减仓，冻结意图。

该规定会让周频换股更慢，F1的每日评估须单独比较；不得用同一开盘价无条件完成任意换仓。
下次若使用分钟数据支持同日先卖后买，另开成交模型版本，不覆盖原日频结果。

## 3. 意图与参考成交

本节保留next_open_reference_v1研究口径；提前结果不包含尚未知晓的次日开盘或实际成交。
日批固定数量/价格条件计划按daily_batch.md第5节另存执行版本，并与本模型对照后才能采用。
未来每个意图包含 signal_date、available_at、strategy_version、pool_version、证券和理由。
冻结排序、买量上限、触发线、初始退出线、最高买价、有效期和当时风险预算。
预算基于信号日净资产并合并account.md的金额/比例限制；执行时只收紧，不因开盘上涨扩股数。
`预计买价=开盘参考价×(1+滑点)`；卖价相反，按证券最小价位作不利方向取整。
这是日线近似成交情景，无法证明开盘观察后仍能按该价格交易；必须同时报告延迟一日压力结果。
近似模型不能单凭压力结果获实盘执行认证；模拟接入前须核对下单时点、可观察信息与可成交价格。
若验证需要更细数据，优先补候选证券的集合竞价/分钟样本，不以全市场分钟库作为首轮前置。
不根据次日收盘或日内最高最低价，决定开盘的选股、数量、排序或是否撤单。

所有新买在执行前逐项核验：

1. 股票仍在当时有效池、具备权限、未停牌且有明确适用交易规则。
2. 开盘处于涨跌停端点时不新买；无涨跌幅限制日仍须具备独立规则和资格。
3. 公司行动校正后向上跳空不超过3%；预计成交价不超过信号均线偏离上限与冻结最高买价。
4. 预计成交价必须高于初始退出线；不能因低开买得便宜而接受已失效结构。
5. 突破版原始开盘应高于冻结HC20，E2应高于信号日前一日最高价且仍满足2R空间。
6. 预计成交价超出合法价格区间则取消买单；不能裁剪到涨停价后宣称买得到。
7. 费用、可用现金、风险、合法数量及实际持仓数均满足；只允许缩量，不因低开扩大冻结买量。

S0不使用第5项趋势触发检查；它仍受现金、权限、退出距离和成交约束。
S0月初选择冻结；仅因现金或名额等待的候选，可在新月前5个交易日重新评估预算后生成次日意图。
S0不得执行到新月第5日之后，其他买单取消原因不重试；不是月中重新选股或补充新候选。
买单仅因执行现金不足而过期时，候选仍可在上述窗口重新冻结；跳空、停牌或结构失效不享受此例外。
同月已成交或沿用旧仓的候选，随后全平也不补开；跨月仍遵守全平后的冷却期。
S0同名旧仓保留原股数与退出线，月度排序不重置止损、不主动加仓。
卖出跳空越过退出线时按可用参考成交情景计损失，不按退出线记成交。
开盘跌停的卖出意图保留；参考卖价越出合法区间时标为不可成交，不用越界价格记卖出。
开盘涨停可卖出是模型假设，须记录并在更保守的双向端点不成交情景复核。

## 4. 数量、持仓名额与重复交易

- 按信号排序先检查单股最小合法买量是否满足全部个体预算，不满足可继续看Top20下一名。
- 选出最多空余名额个候选后等分剩余预算，再按风险和组合上限缩减；受约束余款留现金。
- 组合缩减或执行取消导致零股数时，当次不从更低排名补买，避免使用执行日信息重排。
- 股数向合法集合内取最大可行值；最小200股不必然代表按200股递增，按历史规则逐证券处理。
- 每股总计划风险含全部存量与费用；但v0.3主动加仓关闭，只处理新交易或减仓。
- 减仓优先退出整只的强制卖出，再按比例缩减超限组；合法数量取整后重新校验剩余目标。
- 小额减仓不足合法数量则记录目标偏差，必要时合法全平；不得把残余零股从持仓数中删除。
- 买单取消或参考部分成交后，剩余买量当日过期；卖单未成交部分保留原退出原因。

日线核心模型按冻结数量完整成交或拒绝，不模拟没有证据的盘中部分成交路径。
若未来模拟账户回填真实部分成交，账本须支持；已经买入的少量股数同样占一个名额。
任一事件后持仓身份数不得超过2；一只分批卖出仍算一只，同一代码多批买入不算多只。
同日完全退出后不反向买回，冷却从实际全部卖出后的下一交易日计5日，第6日才允许新信号。

## 5. 退出冲突、回撤和权益账本

退出理由并存时依次处理：账户停用/数据风险 → 交易资格或离池 → 市场降仓 → 个股退出 → 其他减仓。
保留所有命中理由，不同理由对同一股只生成一个合并后的最大必要卖量，禁止重复扣库存。
全平意图一旦形成，在成交前持续保留；趋势恢复不自动撤销，允许卖出后按冷却和新信号再进。
拟定结果字段：signal_date保留首次冻结日，reason为最高优先级，reasons保留累计去重理由；仍待契约实现。
重复触发不重置日期或减少待卖量；新增更强退出条件可升级理由和必要卖量，实际成交后才扣除剩余量。
部分卖出后仍有持仓时，保留入场ATR、跟踪线与持仓名额；只有全平才启动冷却。
回撤状态记录已触发最高严重程度；达到15%后回到12%仍按15%规则，直至满足解除条件。
净值使用实际现金、持股和可识别应收权益；现金分红在权益确认与到账时分别处理，不能重复入账。
送转、配股选择、股息税和退市处置按适用规则；无可靠处置数据不得删掉证券或将账面价格当提现额。

## 6. 回测必备验收样例

至少覆盖：月末名单晚到、全市场漏数、代码变更、除权低开、突破失败低开、涨跌停和停牌。
另覆盖：买入当日卖出受限、两只同时受困、换股无名额、最小买量、零股全平、滑点越界。
费用核对包括最低佣金、法定费率跨生效日、公司行动双计；意图重跑不得重复交易。
所有样例提供输入快照、预期账本和差异说明；实现阶段测试这些行为，不写仅复刻公式的空洞测试。
