# 账户重演、公司行动与日批执行技术协议

> 历史参考：当前方案与待办已合并至[策略研究与实施方案](plan.md)。下文保留原日期记录；“方案被替代”不代表功能已验收。

本协议补齐可信年度回测所需的状态、价格和执行语义。适用50万元、最多两只、全A上月Top20的现金账户；属于待实施设计。
总体架构见[quant_architecture](quant_architecture.md)；具体策略触发仍由signals、levels和execution定义，不由账本决定选股。

## 1. 必须可保存的完整State

| 状态 | 必含内容 |
|---|---|
| 账户 | 可用现金、待到账现金、应收现金/股份、负债及费用、期初资本、最高净值、回撤停用 |
| 持仓批次 | 证券、整数股数、可卖/锁定数量、原始买入日/成本、cycle_id、来源策略版本 |
| 退出信息 | 初始线、当前线、入场ATR、入场后最高收盘、MA下方计数、市场确认计数 |
| 意图 | 稳定intent_id、首次信号日、剩余数量、合法区间、冻结预算/市场上限、到期/重试规则 |
| 权益 | action_id、登记持仓、应收/已付/已到账、税费批次、版本及处理阶段 |
| 运行 | 已完整处理日期、事件游标、输入/规则/参数摘要、冷却记录、随机生成规则 |

状态不得只保存当前股数和现金；缺少待收权益、旧版退出线或最高净值会使跨折净值虚增。
Go函数回调不能作为持久化规则。当前Lot/StopPct等json忽略字段须改为可还原的规则ID及版本化数据。
任何证券尚有股票、锁定红股或应收股票时占持仓名额；仅剩应收现金/税费时不占股票名额，但继续保留经济义务。
同证券卖出后再次买入建立新cycle，旧分红仍归原登记批次；不能串到新买交易上。

## 2. 一天的事件顺序

| 阶段 | 输入和动作 | 不允许的穿越 |
|---|---|---|
| 开始 | 从上一完整日终State恢复，装配当日已生效公司行动及交易规则 | 不能借今日收盘扩大昨日预算 |
| 开盘前权益 | 处理除权、应收/锁定股、实际已到账现金及订单换算 | 不把尚未支付分红当可买现金 |
| 执行 | 仅执行此前冻结意图；资格/限价/停牌核对，按版本费用记真实模拟成交 | 不用今日高低点替换更好的开盘成交 |
| 收盘 | 对存量及权益估值、确认登记持仓、计算回撤和下一日风险意图 | 不把今天触发退出回填成盘中卖出 |
| 22:00决策 | 使用截至截止可得输入生成次日条件计划；回填到账不确定则明确模型假设 | 不把实际次日开盘当成当时已知价格 |
| 持久化 | 独立对账，原子提交事件及完整State；校验通过后发布 | 半天账本不能标记为已完成一天 |

到账只有日期无时刻时使用已登记的保守可用时钟；不能为买单临时假定开盘前已到账。
买入T+1可卖约束与现金结算/可提现语义分开；项目仍不使用本次开盘卖出释放的现金/名额完成同期开盘新买。
净值包含经济权益；可用现金、可提现金额和净资产分开，防止账户已达标但资金仍受困。
事件键至少绑定run、日期、阶段、证券、intent/action及批次。恢复重复遇到相同键时核对内容，异内容阻断。

## 3. 公司行动：事件识别与记账

来源dividend包含预案/决案/实施、登记日、除权日、派息日和红股上市日，不能每一行都记一笔分红。[^1]
先从保留的多版本来源构建实施事件；canonical action_id不得只靠证券/报告期，也不得把所有字段变化当新权益。
用已核实的实施公告、登记/除权日期及方案标识建立关联；相互冲突的同阶段记录保留证据并阻断该事件。
既要保留来源首次观察时间，也要保留可知时间；不知道历史公告版本时标记回顾性重建，不伪造发布时刻。

| 时点/类型 | 处理 |
|---|---|
| 股权登记收盘 | 冻结合资格持仓批次和数量；确认登记权利，不提前把含权价格加上应收造成双计 |
| 除权除息 | 以登记快照确认应收现金/股份；原价估值下计入权益，抵消机械价格调整的会计影响 |
| 派息到账 | 应收现金转可用现金，金额守恒；不重复记一份分红收益 |
| 红股/转增上市 | 应收或锁定股份转实际可交易股；未可卖部分不能提前卖出或释放名额 |
| 卖出/税费结算 | 按冻结税务情景及持股批次确认费用/税负，归原cycle |
| 方案更正 | 新来源版本、差异及受影响run显式记录；不得悄悄回写已发布历史建议 |

简单示例：登记1000股、每股现金0.20元、每股送转0.10股，在同一计价基准确已核验时，应收200元及100股。
除权日应收进入净资产，派息/股份到账只是资产分类变化；禁止到账时再增加相同金额收益。
同一权益份额只能处于应收、锁定实股或可交易实股之一；现金应收与到账现金同样互斥，禁止跨分类双计。
有差异化分红、回购专户剔除、配股/换股、基准股本变化时不得套该算式；需要专项事件适配，未知则阻断受影响账户。
Tushare的cash_div为来源税后字段，cash_div_tax为税前字段；不能用一个统一税后值代替账户的实际持有期税务。[^1]
个人与机构账户税务不同，应明确tax_profile；研究可登记自然人情景，但不能把“机构研究方法”视为机构账户身份。
个人股息税存在按持有期限及转让环节扣收的规则，因此卖出后或收到现金后仍可能有相关义务。[^2]
期末潜在税负采用冻结的应计/清算估计口径并单列；实际结算差额形成事件，不将尚未扣税当永久免税。

## 4. 复权、关键点位与冻结数量

信号价格统一为`P_s×factor_s/factor_t`，t为决策日；成交和持仓估值始终使用原始价格。
滚动实现可累计`P_s×factor_s`，在t除以factor_t还原价格型指标；TR也在同一尺度算，成交额不复权。
历史因子修订触发依赖重建；缺连续窗口、未知因子不代填1。单调队列HC20仍排除信号日。
当持仓跨公司行动，股数、成本、入场ATR、历史最高价、初始/跟踪退出线和待执行意图须一起换算。
仅已核验的简单现金/送转事件可使用明确代数映射；复杂事件不能从factor比例推断现金、送股组成或税负。
未成交新买遇权益变化，首版选择取消原意图，在新尺度的下一日批重新评估；取消规则独立冻结并重跑绩效。
存量卖单按真实可卖股数及规则保留退出义务；不因原股票曾买过而永久阻断已无任何权益义务的未来日期。

盘后先计算合法买入区间[Pmin,Pmax]：退出线以上、追价上限、扩展上限及资格允许价格的交集。
E2还满足`P≤(H+kS)/(1+k)`，来自`(H−P)/(P−S)≥k`；H/S/k均冻结，区间为空则不生成新买。
数量在Pmax及冻结滑点/费用下按最不利计划风险确定，满足单股/总额/现金/1%与2%风险及两只名额。
执行时只核对真实价格与既有仓位变化后的预算；不满足则取消/拒绝，不能盘中扩量或缩量凑成交。
市场实际价格只做执行条件核对；区间外取消，不扩大数量、不替换第三只，不在盘中重新排序。
跳空越过退出线仍可能亏损超过计划1R；止损触发和最终成交价分别记录。

## 5. A股执行适配

交易规则按市场、板块、证券状态、生效起止日和暂缓条款登记，不能用当前名字推断历史ST或将所有股票统一10%。[^3]
最小买量、递增量、零股卖出、最小价位、T+1、涨跌停及新股无涨跌幅限制期分别建字段。
日线无法证明集合竞价排队、部分成交和盘中先后；首版拒绝价格限制端点上无法证明可成交的买卖，并报告拒绝原因。
该假设也可能延迟本来可卖的订单，须呈现敏感性；它是保守执行情景，不宣称所有损失都有严格下界。
不能用全日成交量证明开盘那一刻足以成交；主模型假设、保守拒绝及延迟/成本压力分别展示。
买入延迟压力定义：将原计划执行资格顺延一交易日，数量/区间不重算；重新核验资格、月池、风险停用与T+1。
原意图被撤销、离池或区间失效则取消，不自动追到成交；延迟是执行扰动，不是新增一次选股。
两只同主题或高相关时共享组合风险约束；历史行业缺失须显式未知，不能用当前概念“修复”历史资格。

## 6. 对账、周期与断点验收

每日日终以事件序列独立重建现金、股份及应收，核验`净资产=现金+证券市值+应收权益−负债`。
成交数量与现金使用整数股/金额精度策略；复权和研究特征可用float64，费用舍入时点单独版本化。
生产账本优先金额分或明确的高精度定点累计后舍入；不能每一步随意round以凑齐对账。
周期区分position_closed和economically_final：股数清零但分红/税费待定时，不立刻把最终胜负固定下来。
已核验的应计权益可以进入暂估净PnL，未结算项和不确定性另列；正式胜率使用统一的最终/应计统计政策。
R分母为入场时冻结的计划风险；分红及全部费用归入对应周期净PnL，后续参数不能改写历史R。

| 场景 | 必须一致或解释的结果 |
|---|---|
| 分红登记后卖出，之后派息 | 原cycle收到收益，现金到账不形成新交易胜利 |
| 送转、锁定红股及部分卖出 | 股数/可卖/名额/退出线一致，不重复计价 |
| 卖出后重买同股 | 新旧cycle和税务批次隔离，旧权益不丢 |
| 第一天买入并收盘触发退出 | 最早下一允许时点卖出，不能豁免T+1 |
| 运行中取消/重启或跨12月块 | 恢复后事件、股数、现金及权益与不中断路径一致 |
| 月末/外层折切换参数 | 旧仓保留来源规则，现金和最高净值不重置 |
| 同快照日批/历史重演 | 决策点的特征、意图及冻结股数一致；执行回填分阶段比较 |

仅正确性修复即可改变年度收益，必须生成新模型/执行版本。当前已归档的短区间流水不能替代上述权益验收。
