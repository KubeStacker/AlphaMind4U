## 1. 固定约束与基础计算

| 参数 | 默认值 | 含义/变更方式 |
|---|---|---|
| capital / max_positions | 默认500000元 / 1或2 | 本金可配置；最多两只保持，被困旧仓占名额 |
| universe / rebalance | 上一完整自然月全 A 成交额 Top20 / 月度 | 不递补第21名，不用日均金额 |
| leverage / cash_return | 1倍现金账户 / 0 | 无融资融券；不人为添加现金收益 |
| price_basis | 信号日尺度的复权OHLC；账本原价 | 公司行动单独入账 |
| ma_fast / ma_slow / atr_n | 20 / 60 / 20 | 市场交易日窗口；缺失和停牌见 execution.md |
| momentum_n / slope_n | 20 / 5 | MOM20/RS20；MA20与五日前比较 |
| breakout_n / breakout_field | 20 / close | 最高收盘HC20，不是最高价H20 |
| amount_n / amount_range | 前20日 / [1.2,2.5] | 分母不含信号日，边界包含 |
| max_extension_atr | 3 | 收盘超过 MA20+3ATR 不新买 |
| benchmark | 沪深300价格指数 000300.SH | 信号比较用；绩效分红口径另报 |
| required_history | 每个启用因子的最大窗口需求 | MA60为60点，相关性为61点；不得统一写60 |

资金、总额度模式、现金保留、绝对风险额和目标的完整定义见 [account.md](account.md)。
这些是账户情景，不进入策略参数自动搜索；下文比例是默认情景值，不是引擎硬编码。

## 2. 市场状态

S2/S3及相应分支按 signals.md 顺序匹配状态；数据错误优先，下面为小数比例。
S0/S1固定80%总仓上限，不使用此状态确认，但仍受账户、数据和组合风控约束。

| 参数 | 默认值 |
|---|---|
| breadth_retreat / down_limit_retreat | B<0.35 / D≥0.02（D仅S3） |
| hot_breadth / hot_amount | B≥0.75、V≥1.8 且 B 较昨日下降（仅S3） |
| trend_breadth | T成立、B≥0.55、B不低于五日前 |
| repair_breadth / repair_delta5 | B≥0.40、ΔB5≥0.05 |
| retreat / hot / trend / repair / other_cap | 0 / 0.40 / 0.80 / 0.30 / 0.20 |
| upgrade_confirm / downgrade_confirm | 连续2日 / 当日盘后生成意图 |
| unavailable_data | 禁止新增，处理存量风险，不把缺失当0 |

仓位提升按相同原始状态连续命中计数，变化即清零；下调立即降低目标，不绕过执行时点。
初始状态为数据不可用；首个有效日最多采用20%目标，明确退潮则为0%，第二个连续日再提升。
过热与账户≥15%回撤的“禁止新增”即使仓位未满也生效；提高上限不自动给旧仓加仓。

## 3. 个股、组合与开关

| 参数 | 默认值 | 说明 |
|---|---|---|
| entry_frequency | 每周最后交易日及月末 | F1/E2/E3分支改每日，其他规则不借机改变 |
| rank / tie_break | RS20降序 / 月金额名次、代码升序 | 不拟合综合权重，排序在信号日冻结 |
| initial_stop_atr / trail_atr | 2.5 / 2.5 | 入场信号ATR冻结；退出线只升不降 |
| ma_exit_days / cooldown | 2 / 5交易日 | 两个连续有效收盘；完全退出后五日冷却 |
| pyramiding / fixed_take_profit | false / disabled | v0.3关闭主动加仓与固定百分比止盈 |
| max_holding_days / time_stop | disabled / disabled | 依趋势和离池退出；时间止损只列后续实验 |
| single_cap / total_cap | 0.40 / 最高0.80 | 最终与市场、回撤、行业风险取更严格者 |
| single_risk / aggregate_risk | 净资产0.01 / 0.02 | 计划退出损失含费用，不保证实际最大损失 |
| industry_group_cap | 0.50 | 同一历史有效一级行业；未知按同组处理 |
| corr_n / corr_threshold / corr_group_cap | 60日收益 / >0.8 / 0.50 | 缺失按同组，不替换为0 |
| dd_reduce / dd_freeze / dd_halt | 0.10 / 0.15 / 0.20 | 减半市场上限 / 禁新增且最高20% / 停用 |
| dd_resume | 连续5日回撤<0.08且市场非退潮 | 保留已触发最高级别；20%停用当次运行不重启 |

主动加仓关闭不阻止减仓、公司行动股数变化或未来全平后的新交易；减仓不重置初始ATR与退出线。
获利后不为补足40%权重买回被减掉的数量；同一证券新一轮入场须经过冷却与完整新信号。

## 4. E1/E2/E3 专用参数

| 实验 | 默认值与边界 |
|---|---|
| E1行业 | 剔除自身后有效成员≥10、收益覆盖≥95%、IR20>0、IB20≥0.60、IS>此前20日均值 |
| E1个股 | 个股20日收益>剔除自身后的行业收益，其他沿用S2 |
| E2回踩 | 前5日中至少一日最低价落在其当日 MA20±0.5ATR；不包含信号日 |
| E2缩量 | 前3日金额均值/这3日各自此前20日金额均值的平均值<1 |
| E2转强 | C>昨日H；AR20∈[1.2,2.5]；趋势斜率>0；EXT20≤2 |
| E2退出/空间 | S=前5日最低价-0.5ATR；H20>P且(H20-P)/(P-S)≥2 |
| E3失败突破 | 入场起前5个交易日收盘<冻结入场HC20，下个可执行时点退出 |

E2的H20是含最高价的观察线，不能替换S1/S2的HC20；E2关闭固定止盈，2R不等于必然兑现。
E3跟随F1，不套用到没有突破HC20的E2；多分支不得盘后挑一个当日最有利的信号。

## 5. 执行、费用与数据截止

| 参数 | 默认值/要求 |
|---|---|
| decision_cutoff / timezone | 信号日22:00 / Asia/Shanghai；截止时未就绪则不生成当次新买 |
| daily_publish_target | 拟定23:00前发布下一交易日结果；来源缺失/超时发布明确状态，不伪装完整 |
| result_mode / query_policy | 日批结果快照 / 仅读已发布版本；无结果不在查询线程补算 |
| s0_dependency_wait | 新月前5个交易日；只处理现金/名额等待，不重新选股 |
| intent_expiry | 下一共同交易日开盘参考窗口；取消不自动顺延 |
| fill_model | next_open_reference_v1，详见execution.md；不是成交保证 |
| gap_up_limit / price_extension_limit | 开盘比公司行动校正收盘高>3%取消；预计成交价仍须符合偏离上限 |
| volume_participation | 过去20日成交股数中位数的1%；不使用当日总量决定开盘股数 |
| commission_rate / minimum | 0.0003双向 / 每笔5元：研究情景，未确认真实账户费率 |
| commission_scope | 假定已含券商代收经手/监管费；印花税、过户费另计，禁止重复收取 |
| slippage_bps | 单边10基点；压力20/30基点；1基点=0.0001 |
| statutory_fee_schedule | REQUIRED：按日期/市场/买卖方向生效，缺任何适用段则阻断正式绩效 |
| market_missing_tolerance | 月排名无未解释缺失；B/V/D存在未解释缺口则该日对应状态不可用 |
| optional_factor_missing | 该增强信号不可用；基础版另跑，不在同一run中静默切换策略 |

法定费用是外部规则，不能用自由调参替代；G0交付全回测区间的费率表、出处和对账样例。
每日输出条件计划，不提前使用次日真实开盘；固定数量方案须另冻执行版本，详见[daily_batch.md](daily_batch.md)。
例如印花税在2023-08-28有变更，不能让全历史采用同一税率；详见 [税务公告][tax]。
有公开日期无具体时刻的事件，保守从下一交易日22:00后的决策使用，并标记时间代理假设。

## 6. 调参预算

首轮8个策略版本固定默认参数；诊断指标不自动产生更多交易版本。
家族在开发区冻结后，按 tuning.md 最多两维各3值，共9组含默认中心，完整记录而不无限扩展。
突破家族只搜索突破周期与跟踪ATR倍数，初始ATR倍数固定；E2窗口与空间系数另有明确定义。
这取代v0.3的6个单变量限制；排序替换或新开关属于另一个假设，不能混入本次空间。
数据、费用和执行规则修正不是收益调参，旧结果作废留档；若改变策略假设必须增加试验编号。
不把调大风险预算列为策略优化；账户情景可自由配置但分别比较，样本外访问记录不随新run清零。
